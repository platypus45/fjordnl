# FjordNL: fouten en ideeën

[FjordNL](https://fjordnl.nl/) is een gratis app om Noors (Bokmål) te leren, voor Nederlandstaligen.

Hier kun je laten weten wat er beter kan:

- **Fout in de app**: iets werkt niet, of ziet er raar uit.
- **Foute vertaling**: een Noors woord heeft een verkeerde of onduidelijke vertaling.
- **Fout in een kaart of zin**: een vorm, uitleg of uitspraak klopt niet.
- **Idee**: iets wat je mist of graag anders ziet.

Kies [Nieuwe melding](https://github.com/platypus45/fjordnl/issues/new/choose). Je hebt een (gratis) GitHub-account nodig.

Let op: meldingen zijn openbaar. Zet er geen persoonlijke gegevens in, en ook niet je koppelcode van Sync.

De code van de app staat niet in deze repository.
